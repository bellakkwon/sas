# 자료 패키지 (2026-09-21, 집계·발표자료 전용)

이 폴더는 승인된 공개 안전 산출물만 모은 전달본이다. 원문·행별 예측·개인 식별자·
가중치·인증 정보를 포함하지 않는다. 수치와 이미지·발표 파일의 바이트는 정본 그대로이며,
링크 정리·비공개 경로 가림·승인 범위 밖 문서 연결 해지만 기록된 변환으로 수행했다.

## 구성과 안내

- `presentation/`: 발표 덱(PPTX·PDF·슬라이드 18장, 2026-09-20 디자인 v2;
  파일명은 20260919를 유지)과 이전 제출판 문서 4종(2026-09-19 v1).
  덱은 당시 판이며 최신 결과가 자동 반영된 것이 아니다.
- `poster/`: 포스터(PDF·PNG·HTML·쉬운 설명, 2026-09-20). 이후 결과 반영 여부는 제출 전 확인.
- `explain/`: 프로젝트 설명 페이지와 최신 결과 해설 2종(2026-09-21).
- `diagnostics/`: U5 진단·후속 대조·JEV 비교·JEV 결합 집계(검증 SAS 코드는 제외,
  SAS 저장소의 `followup_20260921_v1` 폴더 참조).
- `diagnostics/historical/`: 과거판 보고서 2종. 최신 결과 해설과 후속 해석이 우선한다.
- `sas-results/`: 실제 검증된 SAS 4단계 실행 반환물(HTML·그림 35개·집계 재출력 CSV).
- `evidence/`: 본문 수치가 계산된 공개 집계 정본(JSON)과 해석 문서.
- `index.html`: 전체 탐색 안내. `manifest.json`: 파일·출처 해시와 변환 기록.

## 최신 결과 요약(발표 보조, 독립 평가 아님)

- U5 기존 시험자료(정상 1,665건·스미싱 652건, 과거 평가 이력 있음):
  DUP 평균이 가장 나았으나 우월 확정 아님.
- KISA 외부 양성 22건(대표 18건은 부분집합): 기준 탐지율 59.09%→조건별 진단.
  정상 후보 250건은 개발용 회귀 검사이며 독립 오탐률이 아님.
- JEV 자동 대체(선택 88건)와 특징 결합(142건): 안정적인 추가 이득 미입증,
  기존 기준선 유지.
- SAS 4단계 실행 검증 통과는 집계 재계산·반환 검증이며, 탐지 성능 개선과 다른 판단이다.
  CAS·VA 신규 검증은 아니다.

