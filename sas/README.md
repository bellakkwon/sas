# SAS 프로그램

모든 활성 SAS 프로그램은 이 폴더에 있습니다. 시작 파일은 [00_RUN_ALL.sas](00_RUN_ALL.sas) 하나이며, 설정과 실행법은 [RUNBOOK.md](RUNBOOK.md)를 따릅니다.

| 프로그램 | 역할 |
|---|---|
| `01` → `02` → `03` → `06` → `05` | 기존 입력 감사, 검증 OOF 메타 회귀, 모델 비교·시각화 |
| `07`, `08` | 외부 유형·연도 분석, 원래 train fold의 FAGE 비교 |
| `04` | 선택 SAS 문자 모델 보조 실험 |
| `11` → `12` → 선택 `13` | A/B 검수·합의 분석, CAS 게시 |
| `14` → 선택 `15` | 기존 KcBERT 집계 시각화, CAS 게시 |
| `21` (내부 `16`·`18`·`19`·`17`) → `99` | U5·JEV·KISA 후속 진단과 반환 ZIP |
| `31` (내부 `30`) → 선택 `32` | 최종 공개 집계 보고서, CAS 전체 읽기 대조·게시 |

공개 입력은 `../data/aggregates/`, 비공개 입력은 `../data/processed/sas/`, 새 출력은 `../outputs/run_<UUID>/`입니다. 입력이 없는 기존 단계는 상태표에서 구분합니다. CAS와 문자 모델은 기본 비활성입니다.

옛 `00_RUN_*`, 복사한 실행 코드, 옛 전달 패키지와 KcBERT Compute 재학습 인계는 [보관 폴더](../archive/sas_cleanup_20260929/README.md)에 있습니다. 현재 실행기에 포함하지 않습니다. 데이터·임계값·평가 분할·기존 결과 수치는 이 정리로 바꾸지 않았습니다.
