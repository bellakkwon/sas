# 신규 KISA 자료 평가 및 기존 정상 후보 검수 계획

작성: 2026-09-21. Orca run_038c277363b4. 모델 추론 전에 메인이 평가 조건을 정한다.

## 순서와 완료 기준

1. E1 Antigravity: 수령 감사의 screened_new_candidate만 입력으로 준비한다. 메인이 원문 연결·정규화·중복 및 본문 판단을 확인하고 평가 목록을 해시로 고정해야 E2에 들어간다.
2. E2 Antigravity: 저장된 DUP 모델을 로컬에서 평가한다. 메인이 점수·판정·분모·모든 미탐을 검사하고 별도 집계로 검산한다.
3. E3 Antigravity: 새 정상 자료가 없으므로 기존 realistic_normal_review_candidates.csv를 개발용 AI 검수한다. 본문 판단을 별도 파일로 작성하고 원 라벨·사람 검수 대기 상태를 보존한다. 메인이 근거와 집계를 검사한다.

## 결과를 보기 전에 고정한 조건

- 출처: external_intake_20260920_v1의 KISA 원본과 감사 결과. 수령 감사는 보존한다. 원문은 비공개, 공개 결과에는 집계만 싣는다.
- 원 라벨: KISA 제공 양성. AI 본문 검수는 위험 요구/모호함을 설명할 뿐 실제 사기 사건을 확인한 라벨이 아니다. 모델 결과를 보고 제외하거나 재라벨링하지 않는다.
- 감사용 정규화는 기존 intake 스크립트와 동일하다. 추론 전 본문 검사에서 FSS 수집 메타데이터 접두어를 발견했다. [FSS]로 시작하고 추출문자: 구분자가 있으면 첫 구분자 뒤를 sms_body로 삼고, 그 외에는 원문을 쓴다. 주 모델 입력은 기존 U5 평가와 같은 normalize_text(mask_sensitive_text(sms_body))다. 원문, 분리된 본문, 마스킹문, 감사용 정규화, 실제 모델 입력을 구분하며 raw 전체 정규화도 보존한다. 화면 OCR 잔여 문구는 임의 수정하지 않고 한계로 기록한다. 구분자 없는 FSS 형식은 조용히 처리하지 말고 중단한다. 이 결정은 모델 점수를 보기 전 변경이다.
- 실제 fit/calibration/development_readout 모델 입력 및 기존 unused_eval 입력에 대해 완전 중복과 char 3~5 TF-IDF 코사인 유사도 0.90 이상을 다시 검사한다. 어휘는 고유 reference와 후보 전체에 fit한다. 해당 항목은 신규 평가에서 제외하되 이유와 결과 목록을 보존한다.
- 남은 고유 감사 템플릿을 실제 모델 입력으로 다시 중복 제거한다. 후보 내부 char 3~5 TF-IDF 코사인 0.90 이상 연결요소를 유사 본문 그룹으로 고정한다. 각 그룹의 모델 입력 SHA256이 가장 작은 항목을 대표로 사용한다. 이 그룹은 실제 캠페인 확정이 아니다.
- 주 분석은 그룹 대표별 탐지율이며 전체 고유 입력별 탐지율을 보조 표로 낸다. 반복 원본 행은 독립 표본으로 세지 않는다. 그룹 대표 분모에도 잔여 의존성이 있을 수 있다.
- 주 모델은 기존에 선택된 DUP seed42. 나머지 seed101/202/303/404는 민감도 확인용이다. 새 자료에서 가장 좋은 시드를 선택하거나 시드별 동일 문자를 독립 표본으로 합치지 않는다.
- 임계값은 matched_kcbert_u5_unused_test_20260918_v1.json의 arm_statistics.DUP.seeds 값을 사용한다. max_length=128, 기존 토크나이저·양성 softmax 열 1·확률 >= 임계값을 그대로 사용한다. 모든 모델 파일·임계값 정본·입력·계획·검수 파일을 추론 전에 해시로 고정한다.
- 학습, 임계값 변경, Jev/API 호출, URL 접속은 하지 않는다. 기존 점수 일부 재현과 독립 계산으로 실행 오류를 검사한다.
- 양성만 있는 편의 표본이므로 오탐률/정밀도/실서비스 정확도는 산출하지 않는다. Wilson 95% 구간은 표본 수 불확실성 참고치이며 수집 편향이나 군집 의존성을 해결하지 않는다.
- 날짜는 제공 CSV 필드다. 실제 수신·발생 시각 또는 미래 시점 평가로 단정하지 않는다.

## 기존 정상 후보 검수 경계

실제 수신 및 연구 동의가 확인된 새 자료가 없다는 사용자 답변을 반영한다. 기존 후보는 이미 개발에 사용한 자료이며 모델 점수로 선별된 이력이 있다. 검수 입력에서는 점수 열을 숨겨 본문을 보되 선별 편향은 남는다. AI 검수는 행별 근거·모호함·개인정보 잔여 가능성을 남기며 실제 정상 여부/발신자/동의/사람 합의를 확정하지 않는다. independent FPR 평가에는 사용할 수 없다. 기존 수집 안내와 양식을 연결한다.

### 사용량 전환 및 후속 실행

Antigravity E2 실행 중 `Individual quota reached`(표시된 reset 약 130시간)로 중단됐다. 초기 scratch 실행은 승인된 최종 산출물로 채택하지 않고, 입력·모델 고정과 메인 독립 계산은 보존했다. Orca ctx_c71a8cb81838은 abandon으로 편집 권한을 해제했고 사용자 터미널은 유지했다. 같은 E2 task를 Muse Spark 1.3 Free ctx_46c45e2f1412로 retry했다. 계산 조건을 바꾸지 않은 재현 실행이며 새 기준을 시험한 평가가 아니다.

E2의 모든 시드 예측·중복 일관성·기존 대조군·고정 파일을 메인이 검산한 checkpoint는 비공개 main_prediction_checkpoint.json이다. 보고서 집계 수정은 별도 완료 기준으로 유지한다. 이 검산 이후 E3 task_ef8a5137b545 / ctx_e18da914b5db를 GPT-5.6 Luna에 배정했다. 기존 ChatGPT 로그인 사용을 확인했고 provider 설정은 바꾸지 않았다. Muse의 E2 보고서 보완과 Luna의 E3 검수는 수정 파일이 겹치지 않는다.

### E3 메인 완료 검사

Antigravity의 문자별 제안을 받은 뒤 메인이 모호함·대상 밖 판정 전부와 나머지 본문의 표본·개인정보 의심 항목을 직접 읽었다. 미확인 발신자·사건에 대한 단정을 낮추고, 부분 식별자·실종 안내·코드의 잔존 가능성 및 짧은 근거 인용을 보완했다. 전체 행의 ID·원본 순서·근거 인용 일치·원 라벨 불변·사람 검수 대기 상태와 CSV/JSON 집계를 별도 검산했다. 원본 범주와 세분화된 제안 범주의 차이를 실제 분류 오류 수로 해석하지 않는다.

정본은 `reports/generated/normal_candidate_review_20260921.json`, 설명은 [검수 결과](../../../docs/research/NORMAL_CANDIDATE_REVIEW_20260921.md)다. 비공개 `annotations.json`과 입력 해시를 `main_review_acceptance.json`에 결합했다. 이는 메인 AI 검사 수락이며 사람 합의가 아니다. 모든 본문을 메인이 수작업으로 재검수했다는 의미도 아니다. 원본 Antigravity 제안과 채택하지 않은 Luna 초안은 이력으로 보존한다.

생성기의 `--check`가 결과를 덮어쓰던 초안 결함을 수정하고 읽기 전용 검사를 통과했다. 출력 변조, 행 순서 오류, 원문에 없는 인용, 사람 합의 플래그 변경, 개인정보 플래그 불일치를 거부하는지 확인했다. 변경된 주석은 이전 수락을 재사용할 수 없다. 원본 CSV·입력 불변, 공개 집계의 행 ID·인용·비공개 경로 미포함 및 비공개 파일 권한을 검사했다. Antigravity 사용자 터미널은 유지하고 이번에 생성한 Luna 터미널은 완료 후 release했다.

요청한 입력 확정·고정 평가·기존 정상 후보 검수를 완료했다. 새 정상 자료 확보와 독립 오탐률, 신규 SAS/CAS/VA 실행, 미탐의 OCR·절단 원인 분리, 발표·공개 후보 갱신은 별도 남은 작업이다. 코드·검수 자료와 달리 실제 정상 여부, 수집 대표성, 사건 진위는 이번 검사로 확정하지 않는다.
