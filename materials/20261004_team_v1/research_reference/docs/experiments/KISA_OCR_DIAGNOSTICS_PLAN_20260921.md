## 고정 입력과 실행 조건

- KISA는 기존 평가의 고유 모델 입력 전체를 사용한다. 기존 유사 그룹·대표 선택을 유지한다. 미탐만 선택하지 않는다.
- 정상 회귀 검사는 기존 검수 후보 전체를 사용한다. 모델 점수로 선정된 train/validation 자료이며 원 출처 정상 라벨 기준의 개발용 점검이다. AI 본문 검수를 정답으로 대체하거나 모호한 행을 제외하지 않는다.
- 원래 U5 test의 새 재평가는 하지 않는다. 새 데이터·외부 API·학습·임계값 조정·URL 접속은 없다.
- 저장된 DUP seed42가 주 모델이며 101/202/303/404는 민감도 확인이다. 같은 시드별 기존 임계값을 모든 조건에 적용한다.
- 모델의 실제 `max_position_embeddings`는 300이다. 300토큰 조건은 이를 초과하지 않는다. 정상 후보에서 더 긴 입력은 여전히 잘리므로 전체 문맥이라고 부르지 않는다.
- 원래 KISA 점수는 기존 저장값과 최대 절대오차 1e-5, 판정 불일치 없이 재현해야 한다.

## 점수를 보기 전에 고정할 변형

1. `original128`: 원래 tokenizer, 128토큰, 오른쪽 절단.
2. `ocr_delete128`: 화면 상태·작성창 UI로 판단한 정확한 문자 구간만 삭제하고 128토큰 처리.
3. `cap300`: 원문 그대로 300토큰 처리. 뒤쪽 내용을 추가로 읽는 효과와 길이 변화가 함께 있다.
4. `ocr_delete300`: 같은 삭제 구간에 300토큰 처리. 2×2 대비로 길이와 삭제의 결합 양상을 확인한다.
5. `ocr_unk128`: 원문 토큰 위치·attention·길이를 유지한 채 OCR 구간과 겹치는 토큰 ID만 UNK로 바꾼다. 삭제에 따른 당겨짐과 구별하는 인공 대조다.
6. `ocr_unk300`: 같은 위치 고정 대조를 300토큰에서 수행한다.
7. `head_tail128`: 기존 진단에 사용한 규칙을 그대로 사용한다. 본문 126토큰 이하는 원래 입력과 동일하고, 더 길면 앞 63개+뒤 63개에 CLS/SEP를 붙인다.

OCR 구간은 변형 추론 전에 AI가 제안하고 메인이 직접 확인한다. 문자 오프셋·원문 인용·판단 이유를 비공개로 보존한다. 브랜드, 배송·주소 요구, 링크, 답장 지시 등 본문 의미를 고치지 않는다. 확실하지 않은 구간은 삭제하지 않는다. 동일한 화면 UI 기준으로 모든 입력을 확인한다. 이 수동 OCR 개입은 진단용이며 배포 가능한 자동 정제 규칙으로 채택하지 않는다. UNK도 자연스러운 정제문이 아니므로 OCR이 미탐의 유일한 원인이라는 인과 주장을 하지 않는다.

## 개선 후보의 사전 판단 기준

실제 후보는 기존 코드에도 있는 `head_tail128` 하나로 고정한다. 다른 조건 중 점수가 좋은 것을 사후 선택하지 않는다. 후보 통과는 모든 시드에서 (a) KISA 미탐을 하나 이상 회복, (b) 기존 KISA 탐지의 신규 미탐 없음, (c) 정상 후보에서 원래 정상 판정을 새 스미싱 판정으로 바꾸는 행 없음이다. 통과해도 독립 평가를 위한 후보일 뿐 기본 탐지기를 교체하지 않는다. 실패하면 그대로 보고하고 같은 자료에서 조건을 반복 조정하지 않는다.

KISA 대표·고유 입력, 정상 후보를 따로 집계하며 분모를 합쳐 종합 정확도를 만들지 않는다. 교정/신규 FP·FN 및 유지 오류, 시드별 결과, 절단 길이, 변경 입력 수를 보존한다. 정상 후보의 오탐은 출처 라벨 기준이며 실제 정상 확인이나 독립 FPR이 아니다. 시드를 독립 표본으로 합치거나 작은 편의 표본에 확증적 유의성 주장을 하지 않는다.

## SAS 전달 계약

기존 오류 진단, Jev 대체 비교, Jev 결합 파일럿, 이번 진단의 공개 집계를 전달한다. 원문·행 ID·개별 예측·가중치·인증 정보·비공개 절대경로는 Git에 포함하지 않는다. 기존 연동 저장소는 현재 확인한 `kimchikingdom/sas`이며 메인이 승인된 파일만 stage·검사·push한다.

이번 집계 CSV 열 순서:
`cohort,seed,condition,n,tp,tn,fp,fn,baseline_tp,baseline_tn,baseline_fp,baseline_fn,corrected_fp,corrected_fn,new_fp,new_fn,threshold,recall,fpr`

cohort는 `kisa_unique`, `kisa_representatives`, `normal_candidates`다. 각 cohort×seed×condition 조합은 정확히 하나이며 모든 조합이 있어야 한다. 양성 없는 층의 recall, 정상 없는 층의 fpr는 빈 셀이다. 모든 숫자는 실제 예측에서 생성하며 예시를 실측으로 채우지 않는다. SAS에서 완전한 키 조합·정수·분모·혼동행렬·쌍별 전이 산술과 Python 집계를 검사하고 그래프를 생성한다.

SAS 실제 서버 실행은 사용자가 수행하며 코드 검토·Python 검산과 구분한다. 기존 실행기를 바꾸지 않고 별도 후속 실행기로 실행별 출력 폴더를 만든다.
