# 공유 자료 검증 스크립트

- `verify_bundle.py`: 정확한 파일 목록·SHA-256·상대 링크·공개 경계 검사. 변조·누락·미등록 파일·symlink를 거부한다.
- `reproduce_public.py`: 저장된 한·두·세 건 집계의 산술, 정상 경고 전이, support 제외 분모, clean_recovery를 검산하고 정본에서 CSV를 다시 만든다. 기본 실행은 읽기 전용이며 `--write`만 outputs에 사본을 만든다.

모델 추론·학습·외부 호출은 수행하지 않는다. 이 검사만으로 원 비공개 행별 예측을 재현하거나 독립 신규 성능을 증명하지 않는다.
