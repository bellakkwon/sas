# 기존 정상 후보 본문 검수 결과

기존 후보 250건을 개발용으로 AI 검수했다. 상태는 `main_review_accepted`이며, 메인 검사 수락은 사람 합의나 실제 정상 판정을 뜻하지 않는다.

## 본문 판단

| 구분 | 건수 |
|---|---:|
| 안내·홍보문 형식과 부합 | 237 |
| 판단이 모호해 추가 확인 필요 | 7 |
| 명시적 위험 요구 | 0 |
| 일반 의견·대화 등 안내문 대상 밖 | 6 |

안내문 형식에 맞는다는 판단만으로 발신자·링크의 진위나 실제 정상 여부를 확인할 수 없다. 본문에서 명시적 위험 요구를 찾지 못한 것도 안전하다는 증거는 아니다.

개인정보·계정 식별자 또는 민감한 코드가 남았을 가능성을 표시한 후보는 30건이다. 부분 마스킹 정보와 공개 실종 안내도 포함한다. 완전한 비식별화 검증이나 현재 사용 가능한 코드 확인 결과는 아니다.

## 검수와 사용 범위

Antigravity가 문자별 근거를 작성하고 메인이 전체 행 연결·근거 인용 일치·상태·집계를 검사했다. 모호함/대상 밖 판정은 전부, 나머지 본문은 표본과 개인정보 의심 항목을 직접 확인하고 보완했다. 생성기의 --check 통과는 의미 판단의 정확성을 독립적으로 증명하지 않는다.

점수 열을 제외하고 검수했으나 후보 선정에는 모델 점수가 사용됐다. 기존 train/validation 자료이므로 사람 합의만으로 독립평가셋이 되지 않는다. 원 라벨과 사람 검수 대기 상태는 유지했고, 독립 오탐률은 계산하지 않았다.

원문·행 ID·URL·호스트·개인정보·비공개 경로는 공개 집계에 포함하지 않는다. 검수 중 링크 접속·모델 추론·원 라벨 변경은 수행하지 않았다.
