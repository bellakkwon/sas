# 데이터셋 분할 기준서

문서 유형: 데이터 준비 단계 산출물 · 자동 생성

이 프로젝트가 내놓는 모든 성능 수치의 전제는 하나다. **테스트셋이 학습셋을 보지
않았다.** 이 문서는 그 전제를 어떻게 만들었고 어떻게 검증했으며 무엇이 남았는지를
한 곳에 모은다.

---

## 1. 분할 정책

| 항목 | 값 | 이유 |
|---|---|---|
| 분할 단위 | **유사 문장 그룹** (개별 메시지 아님) | 같은 캠페인의 변형이 학습과 테스트에 쪼개져 들어가면 성능이 부풀려진다 |
| 유사도 임계값 | 0.9 | 이 값 이상이면 같은 그룹으로 묶는다 |
| 이웃 탐색 방식 | `radius (all neighbours above threshold)` | kNN 상위 k개로 자르면 이웃이 많은 문서의 간선이 잘려나간다 |
| 표현 | TF-IDF 120,000 피처 | **모델이 실제로 학습하는 표현과 동일하게 맞춘다** |
| 난수 시드 | 42 | |
| 층화 | `StratifiedGroupKFold` 중 라벨 비율이 가장 가까운 fold | |
| 임계값 선택 | **validation 에서만** | test 를 보고 임계값을 고르면 test 는 더 이상 홀드아웃이 아니다 |
| test 사용 | **최종 1회** | |

## 3. 누출 검증 — 두 단계로 잰다

### 3-1. 그룹이 분할을 넘었는가

> **`group_leakage_count` = 0**

한 그룹의 메시지가 두 분할에 걸쳐 있는 건수다. 0이어야 하고 0이다.

### 3-2. 그래도 얼마나 닮았는가

`group_leakage_count = 0`은 "그룹이 안 넘었다"만 증명한다. **그룹핑에 쓴 표현과
감사에 쓴 표현이 다르면 여전히 닮은 행이 남을 수 있으므로, 실제 거리를 따로 잰다.**

| 분할 | 행 | 학습셋과의 최대 유사도 | 중앙값 | ≥0.9 행 | 비율 |
|---|---:|---:|---:|---:|---:|
| validation | 2,356 | 0.9212 | 0.3904 | 78 | 3.31% |
| test | 2,317 | 0.936 | 0.3831 | 55 | 2.37% |

중앙값이 0.38~0.39라는 것은 **대부분의 테스트 행이 학습셋과 멀다**는 뜻이다.
남은 2.37%는 그룹핑(전체 코퍼스 어휘)과
감사(학습셋 어휘)의 표현 차이에서 온다. 완전 제거는 불가능하므로 **숨기지 않고
측정해서 보고한다.**

## 4. 이전 결함과 수정 (2026-08-01)

초기 분할은 유사도 그룹을 **kNN 6이웃으로만** 만들었다. 이웃이 6개를 넘는 문서는
간선이 잘려나가 같은 캠페인이 분할을 넘어갈 수 있었다.

| 항목 | 값 |
|---|---|
| 반경 검색으로 관측된 행당 최대 이웃 | **355개** |
| kNN 6 절단이 실제로 간선을 잘랐는가 | **그렇다** |

행당 이웃이 최대 355개인데 6개만 봤다는 뜻이다.
반경 검색으로 바꾸고 전 파이프라인을 재산출했다.

**2026-08-01 이전에 산출된 모든 성능 수치는 무효다.** 분할 누출 결함은 Recall 을
실제보다 좋게 보이게 했다.

## 5. 학습 전용 증강

합성 데이터는 **학습 분할에만** 들어간다. 홀드아웃은 건드리지 않는다.

| 항목 | 값 |
|---|---:|
| 출처 | DimensionV/KR-MOB-SMISHING-v2 (CC BY-NC 4.0, synthetic) |
| 추가된 학습 행 | 109 |
| 기존 코퍼스와 완전 중복 | 0 |
| 홀드아웃과 유사도 ≥0.9로 제외 | 0 |
| train 12,100 → | **12,209** |
| validation / test | 2,356 / 2,317 (**불변**) |
| 홀드아웃 불변 검증 | 통과 |

마스킹 때문에 중복이 1,497건 새로 생겼다는

**중복 제거는 반드시 마스킹 이후에 해야 한다.**

## 8. 이 분할로 주장할 수 있는 것과 없는 것

| 주장 가능 | 주장 불가 |
|---|---|
| 동일 코퍼스 안에서 유사 캠페인 누출을 통제했다 | 다른 출처의 문자에도 같은 성능이 나온다 |
| 잔존 근접도를 측정해 보고했다 | 잔존 2.37%가 결과에 미친 영향이 없다 |
| 임계값을 test 로 고르지 않았다 | 이 테스트셋이 실제 문자 분포를 대표한다 |
