# 연구·데이터·공유 가이드라인

1. 목적은 방어 탐지 성능과 한계 검증이다. SMS의 URL 접속·리디렉션·본문 수집, APK 실행, 외부 확인서비스 자동 반복 호출을 하지 않는다.
2. 원문·전화번호·계좌·주소·인증번호·행별 점수·가중치·키·토큰·로컬 실행 로그는 공개 Git에 넣지 않는다. 파일을 공유하기 전 출처·권리·개인정보를 확인한다. 마스킹만으로 재배포 권리를 얻는 것은 아니다.
3. 원문과 정규화문을 비공개에서 따로 보존한다. explanation은 분류 모델 입력 금지다. 중복 제거와 유사도 그룹 단위 분할, 변형 규칙·시드를 기록한다.
4. 모델 비교는 같은 자료·분할·업데이트 수·지표로 수행한다. 임계값은 검증셋에서 정하고 test를 보고 바꾸지 않는다. 기존 오류 사후 진단과 새로운 독립 평가를 구분한다.
5. 추가학습에 쓴 support는 회복 분모에서 제외한다. 기존 탐지 유지, 새 미탐, 정상 경고 증가도 함께 보고한다. 반복 관측 수를 고유 문자 수로 말하지 않는다.
6. 결과 숫자는 집계 JSON·재계산 CSV를 사용한다. 중간 조건을 보고 고른 예시를 사전 채택 조건이나 검증된 최선 모델로 쓰지 않는다.
7. 새 유형 한 건 대응은 현재 기대와 후속 검증 방향이다. 알려진 한 유형의 개선을 모든 새로운 캠페인 대응이나 실제 피해 방지 효과로 일반화하지 않는다.
8. 수정은 브랜치에서 수행한다. 기존 날짜별 자료를 덮어쓰지 않는다. PR에는 변경 이유, 실행 명령, 입력/출력 해시, 검사 결과와 한계를 적는다. 다른 팀원의 미완료 변경을 초기화하지 않는다.

공개 자료의 패턴 검사는 개인정보 부재나 데이터 이용권을 완전히 증명하지 않는다. 자료별 권리와 사람 검수를 함께 확인한다.
