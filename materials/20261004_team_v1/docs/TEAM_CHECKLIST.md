# 팀원 작업 체크리스트

| 역할 | 시작 | 완료 확인 |
|---|---|---|
| 자료·방법 이해 | README → 결과 요약 → 가이드라인 | 개발/시험/사후 진단 분모 구분 |
| Python·데이터 담당 | 데이터 안내 → 공개 재계산 → 비공개 입력 안내 | 고정 입력·모델·임계값·baseline·지원/평가 분리 기록 |
| SAS 담당 | RUNBOOK → PUBLIC 실행 | 단계 상태·로그·집계 대조·CAS 게시 확인, 실패/건너뜀 구분 |
| 발표 담당 | Canva → 페이지별 본문·대본 | 실제 페이지 순서, 새 유형 기대와 관찰 결과 구분 |
| 통합 검토 담당 | SOURCE_MANIFEST → MANIFEST → 검증 스크립트 | 원본 보존·수치·링크·공개 범위·회귀 검사 |

매 작업마다 담당자, 목적, 입력 버전/해시, 수정 가능 경로, 생성 파일, 명령, 검증 결과, 남은 항목을 적는다. 새 데이터는 기존 평가에 자동 합치지 않는다. 새 모델이나 임계값은 결과를 보고 교체하지 않는다. 다른 팀원의 데이터를 올릴 때 출처·동의 범위부터 확인한다.
