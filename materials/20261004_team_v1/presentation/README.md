# 최신 발표와 대본

[현재 Canva 발표](https://www.canva.com/design/DAHXCfSxsl0/2FrD5AA7B0nb71HTXa4jbg/edit)는 **개요 → 분석 → 평가 → 설계 → 결과** 순서의 54장이다. 팀원은 Canva 계정/공유 권한이 필요할 수 있다. 이 GitHub 업로드는 Canva 권한 설정을 바꾸지 않는다.

- [페이지별 발표자 대본](SPEAKER_NOTES.md): 실제 Canva 페이지 순서. 기존 출력 슬라이드 번호와 혼동하지 않는다.
- [페이지별 본문](SLIDE_CONTENT.md): 화면에서 읽은 텍스트의 보존본. 차트·이미지·디자인은 Canva에서 확인한다.
- [대본 생성 명세](notes_manifest.json), [페이지 원문 JSON](pages.json): 저장 후 읽은 결과의 공유판.

발표 시간은 20–25분 가정이며 실제 리허설 미측정이다. 상세 비교 표는 핵심만 짚고 실험 설정·용어는 질의응답용으로 활용한다. 현재 GitHub 파일은 최신 Canva의 PPTX/PDF 내보내기 파일이 아니다. 이전 발표 파일은 [기존 날짜 자료](https://github.com/kimchikingdom/sas/blob/main/materials/20260921_final_v1/presentation/README.md)에 보존돼 있다.
