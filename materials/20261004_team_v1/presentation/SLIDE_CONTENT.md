## 54페이지

```text
부록 용어

ScamLens

54

용어 정리

탐지율 (Recall)

실제 스미싱 중 모델이 잡아낸 비율

오탐률 (FPR)

정상 문자 중 스미싱이라고 잘못 경고한 비율

오탐 / 미탐

정상을 경고한 실수 / 스미싱을 통과시킨 실수

토큰

모델이 문장을 읽는 글자 조각 단위. KcBERT는 128칸(시작 · 끝 표시 포함)까지 읽음

시드 (반복 실험)

학습 시작 조건을 바꿔 같은 실험을 다시 하는 것. 결과가 우연인지 확인

AUC

스미싱과 정상을 점수로 얼마나 잘 구분하는지. 1에 가까울수록 좋음

정확도 / Brier

정확도: 전체 문자 중 맞힌 비율. Brier: 예측 확률과 정답 간 제곱 오차 평균.

p값

차이가 없다는 가정 아래, 관측한 차이 이상으로 극단적인 결과가 나올 확률
```
